# 组件职责及离线验收边界

## 单一来源

- 总流程SKILL.md定义调度/输入/交付，不复制会话、Hosting或ERP算法。
- 淘工厂登录skill定义浏览器和会话规则；其playwright_session.py是公共适配器唯一实现。
- 淘工厂导出skill管理远端任务证据、下载与发布，兼容模块不复制公共适配器。
- 淘工厂聚水潭skill管理订单查询、范围批准与明确匹配；不能由总流程替代批准。
- 淘工厂合并skill管理工作簿布局和公式；总流程只调用严格合并及一次必要检查。

## 安全回归矩阵

| 场景 | 验收条件 |
|---|---|
| 前一公司完成、下一公司仍是旧会话 | 新公司不导出；输出agent恢复交接；不回退/重复前一公司业务 |
| 导出完成后ERP会话失效 | 原导出凭证复用；恢复只继续ERP及后续，不重导、不重复创建任务 |
| 用户验证码/凭据缺失 | awaiting_user，原公司停留，不启动下一家；同等待事项不重复催问 |
| 恢复后同因再次失败 | 一次恢复边界明确，停止诊断，不循环开页/填密码 |
| 批次续跑顺序、日期、模式、路径变更 | 输入绑定拒绝，不能静默进入新任务 |
| Hosting ACK无编号 | 创建前完整快照；原请求摘要/精确名称/时间窗/新增编号唯一；恢复不再create |
| Hosting明确失败/冲突/列表不完整 | 保留creating现场，不猜最新编号，不重复create |
| 连接页关闭使MCP断流 | 已取得Cookie仍返回；诊断不能把不确定断流假报成确定关闭 |
| 连接页归属不明 | 不关闭；不遍历用户旧标签 |
| 兼容适配器导入 | 与规范模块共享类、缓存、SessionScope和异常身份；缺依赖明确失败 |

所有fixture在临时测试目录；浏览器、网络、业务子进程必须mock。测试不可读取真实Cookie/凭据，也不可使用已交付账单或历史journal作写入fixture。离线通过不等于真实平台全部响应格式验收。统一入口可以自动串行运行无阻塞公司；需要Magpie时必须交接当前agent，Python本身不具备操作用户浏览器或凭据的权限。
