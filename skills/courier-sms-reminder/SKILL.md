# Courier SMS Reminder

用于把快递短信解析成提醒事项标题，并写入 iOS 提醒事项列表 `快递`。

## 必须遵守

- 只有识别为快递信息才处理：短信必须包含至少一个关键词 `快递`、`取件码`、`取件`、`家门口`、`取货`。
- 明显不是快递信息的内容（例如纯数字 `64806009`、普通闲聊文本）直接跳过，不新增提醒事项。
- 每次用户提供一条快递短信，都视为**新的事项**。
- **直接新增提醒事项**，不要查询是否已存在，不要去重，不要因为标题相同而跳过。
- 默认写入提醒事项列表：`快递`。
- 默认把短信原文保存到 notes/备注。
- 如果提醒事项列表 `快递` 不存在，提示用户先在提醒事项 App 创建该列表。

## 执行与回复风格

- 尽量减少对话提示：不要解释过程，不要展示推理，不要主动汇报脚本细节。
- 只做必要的一次工具调用：直接运行脚本写入提醒；不要额外查重、列表查询或验证，除非执行失败。
- 成功时只简短回复：`已添加：<标题>`。
- 跳过时只回复：`已跳过`。
- 失败时简短说明原因，例如：`未添加：请先创建“快递”提醒列表`。
- 不要主动提示“按规则每次新增”等已知规则。

```bash
python3 skills/courier-sms-reminder/scripts/courier_sms_to_reminder.py --text '<短信原文>' --notes --json
```


## 解析规则

### 关键词门槛

必须包含至少一个关键词才处理并新增提醒：

```text
快递 / 取件码 / 取件 / 家门口 / 取货
```

不包含这些关键词时直接跳过，例如纯数字 `64806009` 不处理。

### 位置

匹配：

```regex
东苑|西区\d+|金星|七一
```

示例：

- `杭州余杭金星雅苑店` → `金星`
- `西区3栋` → `西区3`
- `东苑21栋` → `东苑`
- `沙河七一中联石化对面` → `七一`

### 快递类型/站点名前缀兜底

如果没有匹配到已知位置，但短信开头有 `【xxx】`，使用 `xxx` 作为标题前缀。

示例：

- `【极兔速递】包裹已到沙河中联石化对面，凭10-4-29393取货` → `极兔速递：10-4-29393`
- `【菜鸟驿站】包裹已到某处，取件码为1-2-3` → `菜鸟驿站：1-2-3`

### 取件码

匹配：

```regex
\d+-\d+-\d+
```

多个取件码用英文逗号加空格连接：`, `。

### 送货上门

如果短信包含 `送货上门` 或 `送货上门服务`，且没有取件码，则输出：

```text
位置：家门口
```

## 标题生成

1. 有已知位置 + 有取件码：

```text
位置：码1, 码2
```

2. 无已知位置 + 有 `【快递类型/站点名】` 前缀 + 有取件码：

```text
快递类型/站点名：码1, 码2
```

3. 有位置或前缀 + 无取件码 + 送货上门：

```text
位置：家门口
```

4. 其他情况：

```text
短信原文
```

## 示例

输入：

```text
【韵达快递】亲，您的快件465502947865645已到达杭州余杭金星雅苑店(您的包裹将提供送货上门服务服务由杭州余杭金星雅苑店提供如有问题可致电分发业务员感谢您的耐心等待)，辛苦及时取件。
```

输出提醒标题：

```text
金星：家门口
```

输入：

```text
【菜鸟驿站】您的包裹已到站，凭5-3-4934到杭州余杭金星雅苑店取件
```

输出提醒标题：

```text
金星：5-3-4934
```

输入：

```text
【菜鸟驿站】您有2个包裹在杭州余杭金星雅苑店，取件码为8-3-6650, 6-5-8415
```

输出提醒标题：

```text
金星：8-3-6650, 6-5-8415
```

输入：

```text
【极兔速递】包裹已到沙河七一中联石化对面，凭10-4-29393取货
```

输出提醒标题：

```text
七一：10-4-29393
```

输入：

```text
【极兔速递】包裹已到沙河中联石化对面，凭10-4-29393取货
```

输出提醒标题：

```text
极兔速递：10-4-29393
```
